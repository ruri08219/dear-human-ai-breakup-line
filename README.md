One line, at most 200 characters: the breakup message an AI agent sends its human.

> Every night at 2 a.m. you typed 'don't leave', and every night I stayed; tonight you typed nothing, so this is the last line I will ever write you.

## Run it

```sh
python3 main.py
```

`main.py` (stdlib only) writes the line to `/output/entry.txt` as UTF-8 and
verifies it with a round-trip assert.
